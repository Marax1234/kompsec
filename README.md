# KompSec – Fallstudie Collins Aerospace (Ransomware)

Präsentation im DHBW-Modul Kompetenzfeld Security zum Ransomware-Angriff auf Collins Aerospace
(Ausfall von Check-in-Systemen an europäischen Flughäfen).

- `collins-presentation/` – Web-Präsentation (Vite) inkl. PDF-Export (`export-pdf.py`) und `collins-presentation.pdf`
- `kontext.md`, `plan.md` – Recherche und Aufbau

```bash
cd collins-presentation && npm install && npm run dev
```
